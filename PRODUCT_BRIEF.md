# Pitchline — product brief

Affordable SportsCom.pro alternative for football commentators.
Brand: Pitchline. Demo login: demo@pitchline.app / demo1234

## Goals
Replicate SportsCom core workflows, improve UX/live/mobile/automation, ship a working demo today.

## Stack
Next.js App Router, TypeScript, Tailwind, shadcn-style UI, Prisma + SQLite, seed data.

## Screens
Auth, Dashboard, Match Day (pitch + widgets), Speaks, Prep (Assigned→Preparation→Ready→Live→FT), Injuries, Top Scorers/Keepers, Penalties, Venue, Clubs, Weather, Fans, Live event composer, Print/Export, Settings.

## Improvements vs SportsCom
Clear Go Live, always-available event composer, mobile pitchside mode, no overflow modals, export that works, AI-assist templates, data freshness labels.

## Demo data
Fictional league/teams/players only. No SportsCom assets or APIs.
